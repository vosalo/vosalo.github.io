# Mathematics Seminar Website

A responsive, static single-page website for a university or research mathematics seminar.

## Files
- `index.html` — site content and structure
- `styles.css` — layout, typography, responsive styling
- `script.js` — mobile navigation
- `README.md` — this file

## Customize
Open `index.html` and replace:
- seminar title and term
- talk titles, dates, speakers, affiliations, and abstracts
- venue information
- contact email

To change the visual theme, edit the color variables near the top of `styles.css`.

## Run locally
Open `index.html` directly in a browser, or serve the folder with any static web server.

Example:
`python -m http.server 8000`
